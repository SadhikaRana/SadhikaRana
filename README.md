### 📌 Pinned Project

#### 📊 Customer Churn Prediction — Python · XGBoost · SHAP
End-to-end churn prediction system built on the IBM Telco Customer Churn dataset (7,043 records).

- Full pipeline: data preprocessing → EDA → feature engineering → model training → evaluation
- Compared Logistic Regression, Decision Tree, SVM, Random Forest, and XGBoost on Accuracy, Precision, Recall, F1, ROC-AUC — **XGBoost won on F1**
- Integrated **SHAP** for global + individual prediction explainability
- Deployed as a live **Streamlit app** for real-time churn prediction, probability, and risk analysis

`Python` `XGBoost` `SHAP` `Scikit-learn` `Streamlit`
